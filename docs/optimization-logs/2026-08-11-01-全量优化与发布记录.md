## 2. 本轮改动

### 2.1 代码（bot.py）

严重项：

- 取消按钮与任务绑定：取消回调携带 `task_id`，仅当与当前任务匹配时才生效，旧按钮 / Bot 重启后残留按钮不再误杀新任务；
- 批量升级可真正中止：循环开始检查取消标志，收到取消后停止处理剩余项目，汇总消息标注「已中止（剩余 N 个项目未处理）」。

中等等级：

- 原子任务锁：`begin_task()` 用 `asyncio.wait_for(lock.acquire(), timeout=0.05)` 合并「检查 + 获取」，消除快速连点竞态；
- compose 命令探测：优先 `docker compose`（v2 插件），回退 `docker-compose`（v1/v2 独立版），结果缓存；
- 多 compose 文件支持：完整解析 `ConfigFiles` 列表，所有 compose 命令携带 `-f` 参数；
- 项目扫描 TTL 缓存（15s），主面板「🔄 刷新状态」可强制刷新；
- 实时进度：按块读取 stdout，兼容 `\r` 进度输出；进度条按耗时动态推进；
- `ask_prune_confirm` 补 `query.answer()`，扫描期间按钮不再转圈；
- 超时 / 取消分支 kill 后补 `await process.wait()` 并包 try/except；
- 批量升级汇总逐项 `html.escape`；移除每项目的冗余提示消息（减少刷屏）。

轻微项：

- `/status` 校验 `docker ps` returncode；
- 新增 `/help` 命令；`ALLOWED_USER_IDS` 为空时启动告警；
- 主面板按「运行中 / 已停止」分组；服务按钮截断至 64 字符限制内；项目卡片状态图标动态化；
- 滚动审计日志（`RotatingFileHandler`，默认 `logs/ldmg.log`，`LOG_DIR` 可配）；
- `TokenMaskFilter` 同时处理异常 `exc_text`；
- 最终状态消息 `edit_html_safe`：HTML 解析失败自动降级纯文本，避免消息卡死；
- 未知 callback 兜底 `query.answer()`。

### 2.2 配置与工程

- `PAGE_SIZE` 环境变量：主面板每页项目数，默认 6，非法值回退 6；`docker-compose.yml` 与 `.env.example` 已同步；
- Dockerfile 重构：多阶段构建，运行时 `python:3.12-alpine`，静态 docker CLI 28.5.0 + compose 插件 v2.35.1（同时提供 `docker-compose` 回退命令），新增 tzdata、PYTHONUNBUFFERED；体积显著缩小，支持 amd64/arm64；
- 新增 `.dockerignore`（排除 .env、日志、审查文档等）；
- workflow 优化：双平台构建（linux/amd64, linux/arm64）、`GITHUB_TOKEN` 替代 `GH_PAT`、concurrency 取消、30 分钟超时、构建后镜像冒烟测试、Actions 版本升级（消除 Node 20 弃用警告）；
- 镜像引用更新为 `ghcr.io/mbaigc/ldmg:main`。
