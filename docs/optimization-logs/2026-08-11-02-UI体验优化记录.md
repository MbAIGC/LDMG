## 1. 背景 / 目标

用户对主面板与交互提出 5 点体验问题：

1. 路径、服务行前的 emoji 图标不够美观；
2. `/start`、`/list` 等命令未注册到 Bot 命令菜单；
3. 面板标题需要体现 TGBOT 定位；
4. 镜像拉取成功后，拉取过程日志消息太占地方，需要自动删除；
5. 页码下方的长横线在手机端会超长换行。

## 2. 本轮改动（bot.py）

- 主面板标题改为「🐳 Docker Compose 管理面板 - TGBOT版」；
- 路径与服务行去掉 `📂` / `📦` emoji，改为纯文字标签：
  - `路径：<code>/mnt/data1/docker</code>`
  - `容器(N): clouddrive2, openlist, ...`
- 移除页码行下方的长横线 `───────────────────────────`，改为空行分隔；
- `run_command_with_feedback` 新增 `delete_on_success` 参数：命令成功后直接删除过程消息（带失败降级）；
- 项目 / 单服务 / 批量升级的 `pull` 阶段均启用 `delete_on_success`，拉取成功后进度与日志消息自动消失，只保留后续 `up -d` 的消息；
- 启动时通过 `Application.builder().post_init(_set_bot_commands)` 调用 `set_my_commands` 注册 Bot 命令菜单（start / list / status / prune / upgrade / help），无需再手动配置 BotFather。

## 3. 验证结果

- 本地：`pyflakes` 无告警、`py_compile` 通过；
- 引擎冒烟：成功 + 删除消息路径、失败编辑路径、取消路径均通过（真实子进程验证）；
- `ApplicationBuilder.post_init` 签名与 python-telegram-bot 21.6 匹配。

- 暂无；如后续反馈可考虑把 `up -d` 的冗余输出同样收敛（当前已按需保留）。
