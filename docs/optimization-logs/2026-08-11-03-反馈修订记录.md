## 1. 背景 / 目标

用户对 02 号优化提出 4 点修订意见：

1. 拉取日志不应整条删除，而是删除「a70dc7213cc7 Extracting 1 s」这类每层重复进度行，其余日志保留；
2. 「容器(1):」的括号数量去掉；
3. Bot 命令菜单仍未生效；
4. 菜单过期（超时）后能否自动删除失效消息。

## 2. 本轮改动（bot.py）

### 2.1 拉取日志噪音过滤

- 回退上一版的「成功后删除整个消息」逻辑，改为过滤噪音行后正常展示；
- 新增正则 `_PULL_PROGRESS_NOISE_RE`，匹配 `^[0-9a-f]{8,64} (Extracting N s|Downloading N%)` 这类逐层重复进度；
- 实时预览与最终消息都过滤噪音行，`Pull complete`、`Pulled`、错误等其他日志全部保留。

### 2.2 面板容器行

- `容器(N): clouddrive2, ...` → `容器：clouddrive2, ...`，去掉括号数量。

### 2.3 命令菜单增强

- 注册作用域扩展为 4 个：默认（所有私聊）、`all_private_chats`、`all_group_chats`、`all_chat_administrators`；
- 任一生效即视为成功，并加 `_COMMANDS_REGISTERED` 标志避免重复调用；
- `/start` 首次使用时兜底重试注册；
- 注意：菜单生效依赖重新部署新镜像；若 Telegram 客户端未刷新，需要重启客户端或等待菜单缓存刷新；群聊中普通成员默认不显示命令菜单（属 Telegram 平台行为）。

### 2.4 过期菜单自动删除

- callback payload 失效（内存映射清理 / Bot 重启）时，自动删除失效消息并提示「菜单已过期，已自动删除」；
- 删除失败时降级为编辑提示文本，不再只弹 alert。

## 3. 验证结果

- 本地：`pyflakes` 无告警、`py_compile` 通过；
- 引擎冒烟：噪音行正则匹配/保留样本均正确；真实子进程输出中 `Extracting` 行被过滤、`Pull complete`/`Pulled` 保留、消息不删除。

## 4. 遗留事项 / 下次优化建议

- 命令菜单需要用户重新部署镜像后才会真正下发，若仍未出现需检查 `BOT_TOKEN` 有效性；
- 若后续仍觉得拉取消息占位，可考虑「合并 pull 与 up 为同一条消息」的交互改版。
