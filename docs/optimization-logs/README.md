# 优化记录索引

本目录按轮次归档 LDMG 的代码审查、优化与发布记录，方便下一次优化时快速回顾上下文。

## 命名规范

```
YYYY-MM-DD-NN-主题.md
```

- `YYYY-MM-DD`：记录日期
- `NN`：当天序号，从 `01` 开始递增（02、03…）
- `主题`：简短中文描述，如「两轮审查记录」「全量优化与发布记录」

## 记录模板

每份记录建议包含以下小节，便于机器与人工快速定位：

1. 背景 / 目标
2. 审查发现（问题清单，含级别与位置）
3. 本轮改动
4. 验证结果
5. 遗留事项 / 下次优化建议
6. 相关文件

## 新增记录方法

1. 先读本索引与最近一份记录，确认当前进度与遗留事项；
2. 新建文件 `docs/optimization-logs/YYYY-MM-DD-NN-主题.md`（NN 为当天下一个序号）；
3. 按上方模板填写；
4. 在「记录列表」表格追加一行；
5. 提交并推送，同时在主 README 的「优化记录」段落补充链接。
